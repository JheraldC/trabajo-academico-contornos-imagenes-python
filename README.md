# Trabajo académico: detección e interpolación de contornos

Ejercicio de procesamiento de imágenes que carga una imagen, aplica umbralización y visualiza contornos e interpolaciones.

## Capacidades técnicas

NumPy, Matplotlib, scikit-image y SciPy; conversión a escala de grises, Otsu y splines.

## Contenido

- [prueba.py](prueba.py): procesamiento y visualización.
- `gourd.bmp`, `gourd2.bmp` y `gourd3.bmp`: imágenes incluidas.

## Uso

Crear y activar un entorno virtual y ejecutar desde la raíz:

```bash
python -m pip install numpy matplotlib scikit-image scipy
python prueba.py
```

El script utiliza `gourd3.bmp` y abre ventanas de Matplotlib.
